## 🎯 关键解读

### ⭐ 潜血阳性 = 消化道慢性/微量出血证据

- 镜检 RBC 无 + 潜血阳性 = **化学法检出血红蛋白**，但显微镜下未见完整红细胞

- 若为下消化道大量出血，通常镜下可见红细胞或肉眼血便

### 🟢 排除项（好消息）

- **无脂肪小滴** = SEMS 支架 + 十二指肠通畅性 OK，胰酶补充有效，脂肪消化吸收正常，与"恶病质早期"背景下的营养干预方向一致
- **无霉菌** = 长期广谱抗生素（美罗培南→舒普深）+ 化疗后免疫低下，未继发肠道真菌感染
- **镜下无 WBC/脓细胞** = **无肠道感染**，可排除感染性腹泻（如伪膜性肠炎 CDI）；也说明稀便不是感染引起
- **无夏科雷登结晶** = 排除阿米巴/寄生虫/严重过敏性肠炎

### ⚠️ 稀便原因分析

- **不是感染性**（WBC/脓细胞/霉菌全阴）
- **不是脂肪泻**（脂肪小滴阴性）
- **推测原因**：
  - 十二指肠 SEMS 后食物直接快速通过狭窄段 → **倾倒综合征样表现**
  - 全静脉营养 PN + 肠内营养 TPF 快速滴注 → 渗透性腹泻
  - 舒普深/长期抗生素 → 菌群紊乱
  - 帕金森药 + 消化道自主神经病变
